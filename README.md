# Aditya Raj Portfolio

Responsive personal portfolio built with the Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL` to the final public portfolio origin, for example `https://your-real-domain.example`.
3. Start the development server with `npm run dev`.

The public domain is intentionally not guessed. Set `NEXT_PUBLIC_SITE_URL` before deployment so canonical metadata, sitemap, and robots sitemap references use the real URL.

## Available checks

- `npm run typecheck`
- `npm run lint`
- `npm run build`
